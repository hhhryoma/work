# 【協議資料】化石燃料賦課金 収納連携に関する論点(経産省協議用・1枚もの)

- 日付: 2026-07-09(ドラフト)/ 提出者: GX推進機構 賦課金システム設計チーム(想定)
- 目的: 2028年度の賦課金徴収開始に向け、**収納まわりの役割分担と連携方式**について方向性の合意をいただきたい

## 本日決めたいこと(3点)

### 論点1: 収納の役割分担の確認【前提の合意】

当方設計は「**金銭の収納は経産省側、機構は賦課決定・消込・還付**」を前提に進めています。法律上の徴収主体は機構であるため、この分担(収納事務の委任・代行の法的整理を含む)を正式に確認させてください。

### 論点2: 納付番号の採番主体【最重要・設計の分岐点】

収納側で入金を賦課決定に紐づけるキーの持ち方について、**案Aを推奨**します。

| | 案A: 機構が納付番号を採番(推奨) | 案B: 経産省側キーで名寄せ |
|---|---|---|
| 流れ | 機構が賦課決定情報(納付番号・額・期限)を**事前に日次連携**(IF-1o)。収納側は納付番号で受け入れ、同じ番号で納付完了情報を返す | 事前連携なし。収納側は事業者名・金額等で受け入れ、機構が受領後に名寄せ |
| 消込 | 番号一致で**機械的に完結** | 曖昧マッチング。同額複数申告・一部納付で誤消込リスク |
| 事業者影響 | 納付時に納付番号を指定(通知書に記載) | 指定不要だが、照合不能時に双方へ照会が発生 |
| 実績 | 税・公金収納の標準形(ペイジー等と親和) | — |
| 当方評価 | **○** | ×(消込エラーの常態化を懸念) |

**確認事項**: 案Aで進めてよいか。可の場合、納付書を発行しない前提のもと、事業者への納付番号の伝達手段(機構の通知書・ポータル掲載)で問題ないか。

### 論点3: 連携仕様の枠組み【実務協議の開始】

| 項目 | 当方たたき台(詳細: IF仕様書_経産省連携.md) |
|---|---|
| 連携物 | ①賦課決定情報(機構→省・日次) ②納付完了情報(省→機構・日次、**取消レコード含む**) ③延納許可情報(許可主体が省側の場合のみ) |
| 方式 | 閉域網+SFTP、CSV、ヘッダ/トレーラ検証、連番欠番検知、0件連携あり |
| スケジュール案 | 前日分締め→6:00送信→7:00取込→9:00受信結果応答 |
| 別建て協議 | **資金決済**(収納資金の機構への振替スキーム: 還付原資・GX経済移行債償還原資)はデータ連携と分けて財務・会計部門間で協議したい |

## 決定が遅れた場合の影響

- 納付番号方式(論点2)は債権モデル・通知書様式・消込処理の根幹であり、**政省令確定(2027年度内)→2028年度稼働の短工期に直撃**します
- 目標: 論点1・2は**今四半期中**に方向性合意、論点3は担当者間ワーキングを設置し月次で協議
