# アウトプット帳票定義(ドラフト): 通知書・出力帳票

- 対象システム: 化石燃料賦課金管理システム(GX推進機構)
- 作成日: 2026-07-09
- 位置づけ: 業務仕様書のインプット帳票(F01〜F09)と対をなすアウトプット側の定義。**様式の細目は政省令待ちのため項目定義レベルの仮置き**

## 0. 共通要件

| 項目 | 要件 |
|---|---|
| 文書番号 | 全通知書に一意の文書番号を採番(`<種別>-<年度>-<連番6桁>`)。再発行時は枝番 |
| 交付方法 | ポータル電子交付(P-6)を原則、書面交付を併用可。**交付日(ポータルは既読日ではなく掲載日+みなし規定)を記録** — 不服申立期間の起算点 |
| 教示文 | 処分性のある通知(R03〜R06、R09)には**不服申立ての教示文**(申立先・期間)を必須記載 |
| 発行者 | GX推進機構(理事長名)。電子交付時の公印の扱い(電子署名/印影画像)は協議事項 |
| テンプレート管理 | 様式は版番号つきテンプレートとして管理し、政省令の様式改定に改修なしで追従(パラメータ化方針と同じ) |
| 再発行 | 全帳票とも再発行可。原本性は文書番号+版で担保 |

## 1. 帳票一覧

| 帳票ID | 帳票名 | 出力契機(業務) | 宛先 | 処分性(教示文) |
|---|---|---|---|---|
| R01 | 届出受理通知 | A-1 届出の受理 | 事業者 | なし |
| R02 | 申告受付通知(控え) | B-1 申告の受付完了 | 事業者 | なし |
| R03 | 賦課金額決定通知書 | C-1 職権決定 | 事業者 | **あり** |
| R04 | 更正通知書(増額) | C-2 増額更正 | 事業者 | **あり** |
| R05 | 更正通知書(減額) | C-2 減額更正(過納還付の前提) | 事業者 | **あり** |
| R06 | 更正すべき理由がない旨の通知書 | C-2 更正の請求の却下 | 事業者 | **あり** |
| R07 | 還付通知書 | E-3 還付額確定(過納・用途共通) | 事業者 | 用途還付の不認容部分は教示あり |
| R08 | 照会文書/差戻し通知 | B-2・E審査の照会・差戻し | 事業者 | なし |
| R09 | 延納許可(不許可)通知書【候補】 | D-3 延納審査 | 事業者 | 不許可は**あり** |

## 2. 主要帳票の項目定義

### R03 賦課金額決定通知書(職権決定)

| 項目 | 内容 |
|---|---|
| 文書番号・交付日 | 共通要件どおり |
| 宛先 | 事業者名・事業者番号・所在地 |
| 根拠 | GX推進法○条(職権決定)※政省令確定後に条文確定 |
| 対象 | 年度・期(例: 2028年度6月分) |
| 決定の内訳 | 燃料種別ごとの数量・CO2換算量・単価・賦課金額、合計額 |
| 決定の理由 | 無申告のため機構調査により決定した旨+算定根拠(通関実績等) |
| 納付情報 | 納付番号・納期限(**記載要否は論点**。少なくとも納期限は記載) |
| 教示文 | 不服申立先・期間(交付日翌日起算) |

### R04/R05 更正通知書(増額/減額)

| 項目 | 内容 |
|---|---|
| 対象申告 | 申告番号・年度期 |
| 更正前/更正後/差額 | 金額と CO2 量の対比(G-4 の diff 表示と同一データ) |
| 更正の理由 | 職権 or 更正の請求(受付番号)に基づく旨+具体的理由 |
| 増額時 | 追加納付額・納期限(IF-1o 変更連携と整合) |
| 減額時 | 過納額と「別途還付手続を行う」旨(R07 に接続) |
| 教示文 | あり |

### R06 更正すべき理由がない旨の通知書(更正の請求の却下)

| 項目 | 内容 |
|---|---|
| 対象 | 更正の請求 受付番号・請求年月日 |
| 判断 | 更正すべき理由がないと認めた旨+理由(請求理由区分ごとの判断) |
| 教示文 | あり(却下は処分。審査請求の対象) |

### R07 還付通知書

| 項目 | 内容 |
|---|---|
| 還付の種別 | 過納還付(減額更正 文書番号を引用)/用途還付(申請番号を引用) |
| 還付額の内訳 | 過納額(または認容額)+還付加算金(計算式: 元本×利率×日数/365、起算日・終了日)=支払額 |
| 充当 | 未納債権へ充当した場合はその内訳(充当先・充当額)と差引支払額 |
| 支払方法 | 振込先口座(マスク表示)・支払予定日 |
| 一部認容の場合 | 不認容部分の理由+教示文 |

### R09 延納許可(不許可)通知書【候補】

| 項目 | 内容 |
|---|---|
| 対象 | 延納申請番号・対象申告番号 |
| 許可内容 | 延納額・延納後納期限・充当担保(担保ID・種別) |
| 条件 | 期限内不履行時は許可取消+延滞金遡及の旨(仮) |
| 不許可時 | 理由+教示文 |

### R11 受信結果応答(経産省向け・システム間)

| 項目 | 内容 |
|---|---|
| 対象ファイル | ファイル名・受信日時・版番号 |
| 集計 | 受信件数/取込成功/スキップ(E01)/エラー件数 |
| エラー明細 | 連携ID・エラーコード(IF仕様書 §2.3)・対象項目 |

### R12 徴収・還付状況報告(月次/年次)

| 項目 | 内容 |
|---|---|
| 賦課 | 申告件数・決定件数・賦課決定額(燃料種別/事業者規模別) |
| 収納 | 収納額・収納率・滞納件数/額・延滞金 |
| 還付 | 種別ごとの申請/認容/却下件数・還付額・加算金 |
| 更正 | 増額/減額の件数・額 |
| 用途 | GX経済移行債償還原資の報告様式との整合(会計連携 IF-6) |

## 3. 未確定事項

1. 各通知書の法定様式の有無(政省令で様式が定められた場合はテンプレート差し替え)
2. R03/R04 への納付番号・納期限の記載要否(IF-1o の結論に依存)
3. 電子交付の「交付日」の法的取り扱い(掲載日/到達日/みなし到達)
4. 公印・電子署名の方式
5. 不服申立ての種類(審査請求先が機構か主務大臣か)と期間 → 教示文の文言
