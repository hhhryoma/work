# 暫定想定集(ワーキングアサンプション)

- 位置づけ: 課題管理表 #1〜#49 の各課題に**プロジェクトとしての暫定想定を仮決め**し、確定を待たずに設計・実装を進めるための基準書。課題が確定した時点で本表の該当行は「確定」に置換し、差分があれば影響先を改修する
- 想定の性質: **[自決]**=機構/プロジェクトが決めれば確定にできるもの/**[ベット]**=政省令・協議の結果に賭けるもの(外れたら手戻り)
- 大原則: 想定に依存する値はすべて**パラメータ**として実装し、想定変更をリリースなしで吸収する

## 進めてよい範囲・いけない範囲

| 区分 | 内容 |
|---|---|
| ○ 想定で進めてよい | 内部設計・実装・テスト設計・モック・データモデル・パラメータ初期値 |
| △ 条件つき | IF実装(経産省と方式合意前は疎通部分のみ。レイアウトは版管理で差し替え前提) |
| ✕ 想定で進めてはいけない | 事業者向けの対外公表(様式・期限の告知)、経産省合意を前提とした本番接続、教示文の確定 |

## 運用ルール

1. 本表の想定は**設計・実装の正**として扱う(モック・テストデータ・パラメータ初期値は本表に合わせる)
2. **[自決]は機構/PJ内の決裁を経て「決定」に昇格**させる(#16, #18〜#20, #40〜#42, #44, #47〜#49 は早期に昇格可能)
3. **[ベット]は課題確定時に本表を更新**し、差分があれば「外れた場合の手戻り」欄の見積りに従って改修。★★★のベット(#1, #2, #3, #23, #27)は四半期ごとに妥当性を再確認
4. 対外的な確定表明(事業者告知・教示文交付・本番IF接続)は、該当課題の正式確定まで行わない(冒頭の「進めてよい範囲」参照)
