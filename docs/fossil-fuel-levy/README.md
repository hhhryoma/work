# 化石燃料賦課金管理システム 設計ドキュメント

GX推進法に基づき2028年度から始まる化石燃料賦課金の徴収・還付業務をシステム化するための設計ドキュメント一式。

## はじめて参画する人へ

**読み順**: ① `説明資料_プロジェクト概要.md`(制度と全体像を30分で把握)→ ② `業務仕様書.md`(業務・帳票・画面の定義)→ ③ 担当領域の詳細(IF仕様書/帳票定義/画面モック)→ ④ `課題管理表.md`(いま何が決まっていないか)

## ドキュメント一覧

| ファイル | 内容 | 主な読者 |
|---|---|---|
| `説明資料_プロジェクト概要.md` | 制度の基礎知識、システム全体像、用語集、FAQ | 新規参画者全員 |
| `業務仕様書.md` | 主要業務(A〜F系17業務)、インプット帳票(F01〜F09)の項目定義、画面一覧(P系/G系)、追加検討要素 | 業務設計・開発全員 |
| `IF仕様書_経産省連携.md` | 納付完了情報(IF-1a)・延納許可(IF-1b)・賦課決定情報(IF-1o)のレイアウト・エラー処理・責任分界 | IF担当、経産省協議担当 |
| `帳票定義_通知書.md` | アウトプット帳票(R01〜R12)の項目定義、教示文・交付日管理の共通要件 | 帳票担当、業務設計 |
| `画面イメージ_システム全体.html` | 事業者ポータル+内部業務の10画面HTMLモック | 画面設計、レビュー用 |
| `画面イメージ_還付申請.html` | 還付申請(過納・用途)の4画面HTMLモック | 画面設計、レビュー用 |
| `課題管理表.md` | 全文書の未確定事項の一元管理(確定時期・影響先つき) | PM、全員 |

## ID体系(横断ルール)

| 体系 | 意味 | 定義場所 |
|---|---|---|
| A-1〜F-2, D-3/D-4 | 業務ID(【候補】=政省令確定後にスコープ判断) | 業務仕様書 §1 |
| F01〜F09 | インプット帳票 | 業務仕様書 §2 |
| P-1〜P-7 / G-1〜G-8 | 画面(P=事業者ポータル、G=内部業務) | 業務仕様書 §3 |
| R01〜R12 | アウトプット帳票(通知書等) | 帳票定義_通知書 |
| IF-1〜IF-7(IF-1はa/b/oに三分化) | 外部インターフェース | 業務仕様書 §6.2、IF仕様書 |
| LV-/RF-/NT-/ENN-/TN- | 申告/還付/届出/延納/担保の番号例(モック内) | 画面モック |

## 大前提(変わらない限り全文書に共通)

- 対象は化石燃料賦課金のみ(特定事業者負担金・排出量取引は対象外)
- 納付書発行・督促状発行はシステム対象外
- 納付完了情報は経産省より連携される(※この前提自体が協議事項 — 課題管理表参照)
- 単価・期限・利率・様式は政省令待ち(2027年度内確定見込み)。すべてパラメータ化して設計
