# 課題管理表(未確定事項の一元管理)

各設計書に散在する「政省令待ち」「協議事項」を横串で管理する。**本表がマスタ**(各設計書は本表を参照)。

- 優先度: ★★★=設計の根幹(決まらないと後戻り大)、★★=領域内で影響大、★=確定待ちで進められる
- システム影響度: **大**=モデル/アーキテクチャに波及、**中**=機能追加・改修、**小**=設定/帳票/運用で吸収、**なし**=制度・運用のみ

## 運用ルール

- 課題の追加・確定時は本表を更新し、出典側の文書にも反映する(本表がマスタ)
- ★★★は要件凍結(2027年度)を待たず、複数案の設計(案A/案B)を先行して用意する
- システム影響度「大」の課題は、確定前に**どちらに転んでも作り直しにならないヘッジ**をデータモデル・状態遷移に講じる(#22, #23, #40, #42 はヘッジ済み)
- 「確定見込み: 協議次第」の項目は、経産省協議の場が設定され次第、期日を記入する
