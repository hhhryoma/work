# 参考資料: 石油石炭税納税申告書の構成(F02設計の手本)

- 出典: 税関「内国消費税関係[CC様式]」の公式様式・記載要領(2026-11 取得)
  - 申告書本体: `naisho_18.pdf` / Word版 `naisho_18.doc`
  - **記載要領(書き方)**: `naisho_18k.pdf`
  - 付表: `naisho_19.pdf` / `naisho_19.doc`
  - いずれも `https://www.customs.go.jp/kaisei/youshiki/form_CC/` 配下。一覧は `form_CC.htm`
- 位置づけ: 本書は**参考制度の実物**の記録。F02(化石燃料賦課金申告書)の項目設計の根拠として参照する
- 注意: これは**引取り(輸入)分=法15条2項の特例申告**用。移出(採取者)分は国税庁様式が別にある
- 数値入りの記載例: `帳票イメージ_申告書記載例.html`(架空データ。本体+付表、記載ポイント、検算つき)

## 1. 申告書本体の構成

### ヘッダ
| 欄 | 内容 |
|---|---|
| 標題 | 「令和__年__月分 石油石炭税納税申告書(法第15条用)」+ **順号** |
| 提出先 | ○○税関長 殿 |
| 申告書の種別 | 期限内/期限後/修正/**還付請求**申告書 — 不要の文字を**二重線で抹消** |
| 納税地 | 法15条1項の**国税庁長官の承認の際に指定を受けた場所** |
| 住所・氏名又は名称及び代表者氏名(フリガナ)・電話番号 | 法人は本店所在地+代表者の役職名及び氏名 |
| 同上代理人 | **あらかじめ代理人の届出をしてある場合等に限る**(役職名または職業+氏名) |

### 集計欄
| 欄 | 内容 |
|---|---|
| ① | 税額の合計額 |
| Ⓔ② | 控除(還付)を受けようとする金額 = **災害控除**明細書の「控除(還付)税額⑤」の合計 |
| Ⓕ③(②−①) | **還付を受ける金額**(②>①の場合) |
| Ⓖ④(①−②) | **納付すべき税額(100円未満の端数切り捨て)** — 様式に「00」が印字済み |
| Ⓘ⑤ | 修正申告前の確定額(還付の場合は「−」印を付す) |
| Ⓙ⑥(④−③−⑤) | 差引納付すべき税額(100円未満切捨て) |

### 右側欄
Ⓚ還付を受けようとする銀行又は郵便局(銀行振込/ゆうちょ/窓口受取り)/Ⓛ期限後・修正申告をする理由・事情/Ⓜ添付書類/Ⓝ摘要/**※Ⓞ納期限延長の場合の延長後の納期限**/**※Ⓟ納期限を延長した納付すべき税額**/※通信日付印/※確認(**Ⓞ・Ⓟを含む※印欄は税関記入欄で、申告者は記載しない**)

## 3. F02設計への示唆(反映済み・要検討)

| # | 発見 | 設計への反映 |
|---|---|---|
| 1 | **課税物件区分が2階層+小計**(ガス状炭化水素→天然ガス/その他) | F02明細に区分階層と小計行。燃料種別マスタに課税物件区分(大)を持たせる |
| 2 | **統計細分(HS)欄が付表にある** | F03に「統計細分」を追加(課題#35の単位問題の判別キーにもなる) |
| 3 | 課税標準数量は**ℓ/㎏位まで** | 内部は賦課単位(kL/t)で保持しつつ、**申告書の表示単位(ℓ/㎏)**を別に持つ |
| 4 | **「還付請求申告書」という申告類型** | 控除額>税額のとき**申告書自体が還付請求**になる。E-1/E-2とは別の第3の還付入口(課題#54) |
| 5 | **災害控除は期限内申告のみ**(期限後・修正申告では控除・還付を受けられない) | 控除の可否を申告区分で判定するルール(課題#54) |
| 6 | **納期限延長の欄(Ⓞ・Ⓟ)は※印=税関記入欄**。申告者は書かず、延長は別様式「石油石炭税納期限延長申請書(税関用)」(`naisho_22.pdf`)で申請する ※当初「申告書と一体の可能性」と記載していたが、様式実物の確認により訂正 | 延納申請(F08)を**申告書と別帳票**とする現行設計と整合。延長後納期限・延長税額は**受付側(機構)が申告に紐づけて持つ項目**として設計する。延長税額が納付すべき税額と別欄である点から、一部延納(1申告2納期限)は申告単位で表現され得る |
| 7 | 修正申告の⑤は「修正申告前の確定額」。還付だった場合は「−」印 | 増額方向の是正が修正申告、減額方向は更正の請求という整理と整合 |
| 8 | 相続人・合併法人の記載方法が**様式レベルで規定** | 課題#42(承継)・#44(相続)の裏付け。申告者欄に被相続人・被合併法人を併記する構造 |
| 9 | 代理人は**事前届出が必要** | 想定#18「委任届出制」と整合 |
| 10 | **順号**欄がある | 申告書の連番管理 |
| 11 | ※印欄(通信日付印・確認)は受付側記入 | 電子申告では不要(ポータルの受付日時で代替) |

## 4. 端数処理の実際(想定#34の是正根拠)

石油石炭税は**従量税**で課税標準が「数量」であるため、金額ベースの課税標準に対する1,000円未満切捨て(国税通則法118条相当)は適用されない。記載要領で確認できるのは:

- **納付すべき税額(④)の100円未満切捨て**
- **差引納付すべき税額(⑥)の100円未満切捨て**

の2点のみ。賦課金も従量(CO₂量)ベースのため、同じ整理になる見込み(課題#34)。
