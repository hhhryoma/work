# 制度設計シナリオと影響分析(ドラフト)

- 位置づけ: 政省令(2027年度確定見込み)を先読みした現実的な制度設計の予測と、シナリオ別のシステム影響整理。予測の根拠は法定済み事項+参考制度(石油石炭税・温対税・消費税)の前例
- 関連: 課題管理表 #23〜#28、データモデル(ヘッジ済み属性)、説明資料_プロジェクト概要

## 1. 現実的な制度設計の予測(本命シナリオ)

| 設計項目 | 予測 | 根拠 |
|---|---|---|
| 賦課方式 | 上流一括・申告納付方式(期間申告) | 石油石炭税踏襲が最小コスト。改正法が申告・納付期限・滞納処分を法定済み |
| 期別 | 月次申告(または年次+中間納付) | 石油石炭税が月次。償還原資の平準化要請 |
| 輸出・国内非使用 | 納付者自身の申告時控除+事後判明分の還付 | 「移出とみなす」「減額」規定が2025年改正で法定済み |
| 用途還付の対象 | 当初は狭く限定(石化原料・特定産業等、石油石炭税の減免対象と平仄) | 既存減免用途に賦課すると二重負担の政策矛盾 |
| **申請者(最重要)** | **型1: 納付者還付型+使用者の用途証明** | 機構の徴収網が小さく直接相手を数百社に保つ必要/税務署網が使えない/石油石炭税の証明スキーム(用途証明・証明機関)を流用可能 |
| 証明方式 | 帳簿方式+販売者証明・用途証明(インボイスなし) | 消費税ですら帳簿方式で30年運用 |
| 少量輸入者 | 免税点(少量除外)の可能性 | 徴収コスト>賦課額の逆転防止 |
| 延納・担保 | 石油石炭税型(申請+担保+最長1〜2か月) | 法18条の建付け |
| 開始時経過措置 | 開始前在庫は対象外 | 移出・引取時点賦課の定義から帰結 |

**型1に着地した場合の重要な帰結**: 還付申請者=納付者自身のため、適用単価のビンテージ問題(課題#25)は自然消滅する(自分の納付単価を当然に知っている)。使用者(加工事業者=みなし納付者)は用途証明の発行者としてのみ登場し、経済的還元は価格交渉に委ねられる(苛性ソーダ型)。

**リスクシナリオ**: 運輸系など一部用途で型2(使用者還付。温対税還付の前例)が併存する可能性。この場合、みなし納付者の申請受付(書面+代行入力)・簡易登録が実装スコープに昇格する。

## 2. シナリオ別のシステム影響

### 本命(型1・月次・帳簿方式)— 現行設計はほぼ無傷

| 設計資産 | 影響度 | 内容 |
|---|---|---|
| 業務仕様書(A〜F系) | 軽微 | 業務の増減なし。E-2の申請者=納付事業者で確定 |
| F05 用途還付申請書 | 軽修正 | 使用者(証明発行者)情報・用途証明書番号の欄追加(反映済み) |
| データモデル | 軽修正 | 用途証明書エンティティ追加(反映済み)。申請者FK分離は型2への保険として維持 |
| 画面(P-5/G-6) | ほぼ無傷 | 単票申請型のまま。証明書番号入力欄の追加程度 |
| 二重還付防止 | 簡素化 | 申告番号ベースのチェックが有効+証明書番号トレースを補助 |
| IF-1(経産省連携) | 無傷 | 還付は機構完結 |

### 条件つきで追加される要素

| 条件 | 追加要素 | 影響度 |
|---|---|---|
| 証明機関スキーム採用(課題#26) | 事業者マスタ「証明機関」区分(ヘッジ済み)、証明書の取りまとめ一括受付(CSV) | 中 |
| 免税点の導入 | 届出審査の対象判定、申告義務有無の管理 | 小〜中 |
| 型2が一部用途で併存(課題#23) | みなし納付者の簡易登録+書面代行入力の実装昇格。台帳CSV取込+四半期申請型のF05変形 | 中〜大 |
| GX-ETS二重賦課調整が還付型(課題#27) | 還付の新類型(負担金調整還付)の追加 | 大 |
| 将来のインボイス化(§3 Phase 3) | 発行事業者登録簿の公開照会、P系証明書発行機能 | 大(数年先) |

## 3. 消費税の制度設計からの借用(参考整理)

| 消費税の要素 | 賦課金への転用 |
|---|---|
| 多段階課税+仕入税額控除 | ✕ 借りない(法が上流一括賦課を規定。対象が数万者に爆発) |
| **インボイス(適格請求書)** | ◎ 課税技術でなく**証憑技術**として本命。「賦課済証明書」(登録番号・証明書番号・数量・賦課年度・単価・相当額を記載)が賦課済み証明/ビンテージ/多段流通/還付額判定/二重還付防止を一括解決 |
| 輸出免税+還付 | ○ 型として借用(輸出控除・還付と同型) |
| 免税事業者(免税点) | ○ 少量輸入者の除外に応用 |
| 中間申告 | ○ 期別設計の選択肢 |
| 簡易課税 | △ 少量者向けみなし係数 |

**段階導入ロードマップ(消費税の歴史をなぞる)**:
- Phase 1(2028〜): 帳簿方式+販売者証明・用途証明(石油石炭税型)
- Phase 2: 還付対象拡大時に「賦課済証明書」の様式法定化(記載事項統一)
- Phase 3: 電子インボイス(Peppol等)相乗りで電子化。消費税インボイスへの記載欄追加なら事業者負担最小

Phase 3 は2028年度システムのスコープに**入れない**(制度提案として保持)。ただし証明書番号マスタ(用途証明書エンティティ)だけは Phase 1 から持ち、将来のインボイス番号に読み替え可能にしておく。

## 4. いま確定してよい設計方針

1. 現行設計(型1前提)を主線とする
2. 先行ヘッジ(反映済み): F05の使用者情報欄/用途証明書エンティティ/還付事案の申請者FK分離・受付チャネル区分/事業者区分(非納付・証明機関)/承継構造/還付返還債権の発生源
3. 政令確定時(2027年度)の分岐点は「申請者の型(用途別)」「証明機関スキームの有無」「GX-ETS二重賦課調整の形」の3つ。上記ヘッジによりいずれも作り直しは発生しない
