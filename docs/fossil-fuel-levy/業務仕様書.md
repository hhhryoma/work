# 化石燃料賦課金管理システム 業務仕様書(ドラフト)

- 作成日: 2026-07-09
- 根拠制度: GX推進法(脱炭素成長型経済構造への円滑な移行の推進に関する法律、令和5年法律第32号)/2025年改正法(徴収実務の法定化)
- 制度開始: 2028年度(令和10年度)〜
- 徴収主体: GX推進機構(経済産業大臣認可法人)

## 0. 前提・システム化スコープ

| 項目 | 前提 |
|---|---|
| 対象 | 化石燃料賦課金のみ(特定事業者負担金・排出量取引は対象外) |
| 利用者 | ①事業者(化石燃料輸入事業者等)向けポータル ②徴収側(機構職員)内部業務画面 の両方 |
| 対象外 | 納付書発行、督促状発行 |
| 収納連携 | 納付完了情報は経産省より連携される(本システムは受領・消込のみ) |
| 未確定 | 賦課金単価・還付加算金利率・申請期限・様式細目は政省令待ち(仮置きで設計) |

> 用語注記: 本書および関連文書の「賦課決定」は、賦課方式(申告納付方式/賦課決定方式)の確定前における便宜上の呼称であり、「賦課金額の確定(申告による確定を含む)」の意で用いる。

## 1. 主要業務

### 業務一覧

| # | 業務 | 概要 | 主担当 | システム化 |
|---|---|---|---|---|
| A-1 | 事業者届出の受付 | 化石燃料採取者等の届出(新規・変更・廃止)の受付・審査・登録 | 事業者→機構 | ○ |
| A-2 | 事業者マスタ管理 | 事業者情報・還付先口座等の管理 | 機構 | ○ |
| B-1 | 賦課金申告の受付 | 燃料種別ごとの数量・CO2量・賦課金額の申告受付 | 事業者→機構 | ○ |
| B-2 | 申告審査 | 形式チェック、輸入通関実績等との突合、疑義照会・差戻し | 機構 | ○ |
| B-3 | 期限・無申告管理 | 申告期限の管理、未申告者の抽出 | 機構 | ○ |
| C-1 | 賦課金額の決定 | 無申告時等の職権による賦課金額決定 | 機構 | ○ |
| C-2 | 賦課金額の更正 | 増額更正(職権)/減額更正(更正の請求 or 職権) | 機構 | ○ |
| C-3 | 通知書の作成・交付 | 決定通知・更正通知・還付通知等の作成/ポータル交付 | 機構 | ○(納付書は対象外) |
| D-1 | 納付完了情報の取込 | 経産省からの連携ファイル受領・検証・消込 | 経産省→機構 | ○ |
| D-2 | 収納状況管理 | 賦課決定額と納付額の突合、滞納・延滞金の把握 | 機構 | ○(督促状発行は対象外) |
| E-1 | 過納還付 | 更正の請求受付→審査→減額更正→過納額+還付加算金の還付。職権による減額更正(C-2)からも同経路でE-3へ接続 | 事業者⇄機構 | ○ |
| E-2 | 用途還付 | 用途還付申請(輸出等の国内非使用・政令減額用途)受付→審査→還付 | 事業者⇄機構 | ○ |
| E-3 | 還付支払 | 還付額確定、振込データ作成、支払結果管理 | 機構 | ○ |
| F-1 | 単価・係数マスタ管理 | 年度別賦課金単価(政令)、燃料種別CO2排出係数の管理 | 機構 | ○ |
| F-2 | 統計・報告 | 徴収・還付状況の集計、主務大臣報告資料 | 機構 | ○ |
| D-3 | 延納管理【候補】 | 延納申請の受付・審査・許可/却下、延納期限管理 | 事業者⇄機構 | △(政省令確定後に判断) |
| D-4 | 担保管理【候補】 | 担保の登録・評価・充当・解除(個別/包括) | 事業者⇄機構 | △(政省令確定後に判断) |

> 【候補】について: 「延納の場合の措置」は2025年改正で法定済み(詳細は政省令待ち)。担保はGX推進法の条文上未確認だが、参考制度の石油石炭税法18条(納期限の延長)が「申請+税額相当の担保提供、最長2か月、個別/包括担保」の建付けであり、同様の担保徴取が導入される蓋然性が高い。延納許可は消込の期限判定・延滞金計算に影響するため、機構側で持たない場合でも**延納許可情報の連携受領**は必須となる点に注意。

## 4. 制度スケジュールと設計上の参考値

| 時期 | 内容 |
|---|---|
| 2023年5月 | GX推進法成立・公布(令和5年法律第32号。賦課金の基本枠組み:第11条〜第26条) |
| 2025年5月 | 改正法成立(納付期限・滞納処分・国内非使用燃料の減免等、徴収実務を法定化) |
| 2026年4月 | 改正法施行(排出量取引の義務化が先行) |
| **2027年度内** | **賦課金の政省令(単価・対象燃料・係数・手続様式)決定予定 → 本設計の確定タイミング** |
| 2028年度 | 化石燃料賦課金 徴収開始 |

- 賦課金単価の想定値(政府試算ベース・確定値ではない): 2028年度 約2,500円/t-CO2 → 2030年度 約5,000円 → 2035年度 約10,000円
- 帳票様式の設計参考: 石油石炭税納税申告書(税関様式 C-2-3508。油種・数量・税率・税額・控除還付・保税地域等)、温対法排出量算定報告様式(燃料種別・使用量・単位発熱量・排出係数・CO2換算)
- 事業者には帳簿記載義務・機構の報告徴収への対応が課される見込み(政省令待ち)。輸入記録・CO2算定根拠の長期保存を想定

## 5. 主要な未確定事項(政省令待ち・関係機関協議)

1. 申告・納付の期別(月次/年次)、申告期限・納付期限
2. 賦課金単価(円/t-CO2、年度別政令)と対象燃料・CO2係数の公定値
3. 賦課方式の最終形態(申告納付方式か賦課決定方式か。参考の石油石炭税は申告納付方式)
4. 政令減額(用途還付)の対象用途リスト・申請期限
5. 「更正の請求」「還付加算金」に相当する制度の条文上の根拠(国税通則法等からの類推であり、規定の存否自体が政省令待ち)、および利率・期間
6. 経産省との納付完了情報連携仕様(ファイル形式・頻度・リトライ)
7. 輸入通関データ(税関/NACCS)との突合可否・取得経路
8. 帳簿記載義務・報告徴収の具体要件(事業者側対応)
9. 延納の要件・期間・担保の要否(担保が要る場合の種別・評価方法)【D-3/D-4のスコープ判断に直結】
10. 延納許可の主体(機構か収納側か)と、許可情報の連携方法
11. 収納主体の最終確認 — 法律上の徴収主体はGX推進機構。「金銭の収納を経産省が担い納付完了情報を連携する」という本書の前提自体が関係機関協議事項

## 6. システム化に向けた追加検討要素(洗い出し)

主要業務・帳票・画面以外に、システム化の計画・設計で決める必要がある要素。

### 6.1 機能面のギャップ(本仕様書の業務一覧に未収載のもの)

| # | 要素 | 内容・論点 |
|---|---|---|
| 1 | 本人確認・認証 | 事業者ポータルのログイン方式(GビズID連携が政府系の標準)。委任(代理申告:通関業者・税理士等)を認めるかで権限モデルが変わる |
| 2 | 決裁ワークフロー | 賦課決定・更正・還付支払は職員単独でなく審査→承認の多段決裁が必要(職務分掌・金額による決裁権限)。承認ルートの設計 |
| 3 | 通知書の電子交付 | 決定通知・更正通知・還付通知の様式管理、電子交付(ポータル掲載)と書面交付の併用、交付日管理(不服申立期間の起算) |
| 4 | 不服申立て(審査請求)対応 | 賦課決定・更正への不服申立ての受付・経過管理。処分の執行状況との紐づけ |
| 5 | 報告徴収・立入検査支援 | 機構による報告徴収・帳簿確認の記録管理(事案管理、指摘・是正の追跡) |
| 6 | 年度切替・過年度処理 | 単価・係数の世代管理(実装済み方針)に加え、過年度申告の遡及更正、年度末の債権残高繰越 |
| 7 | 債権管理・会計連携 | 賦課決定=債権発生。機構の会計システム(GX経済移行債の償還原資管理)への仕訳連携、収納日次残高の照合 |
| 8 | 還付支払の銀行連携 | 全銀フォーマットの振込データ作成・支払結果(不能)の取込、口座名義照合 |
| 9 | 大量処理・一括操作 | 期限一括督促(対象外だが抽出は必要)、一括承認、CSV一括取込のエラーハンドリング(部分成功の扱い) |
| 10 | 照会・問合せ管理 | 審査差戻し・照会のやりとりをポータル上のメッセージとして記録(メール通知併用) |

### 6.3 非機能・基盤面

| # | 要素 | 論点 |
|---|---|---|
| 1 | セキュリティ基準 | 政府情報システムに準ずる場合、ISMAP登録クラウド・政府統一基準群への準拠が要件になり得る |
| 2 | 監査証跡 | 賦課金額・還付額に関わる全操作(入力・承認・マスタ変更)の操作ログ。金銭に直結するため改ざん検知まで必要か検討 |
| 3 | データ保存期間 | 帳簿保存義務(7年程度と推定)に合わせた申告・証憑データのアーカイブと法定保存 |
| 4 | 可用性 | 申告期限直前のピーク(全事業者が集中)に耐える設計。期限日のシステム障害時の期限延長運用ルール |
| 5 | 帳票出力基盤 | 通知書・控え・統計のPDF生成。様式改定(政省令)に追従しやすいテンプレート管理 |
| 6 | パラメータ化 | 期別・期限・利率・単価など政省令待ち項目は全てマスタ/設定値として外出しし、確定後に改修なしで設定変更できる構造にする(2027年度の政省令確定→2028年度稼働の短期対応の要) |
| 7 | データ移行・初期登録 | 制度開始時の事業者一斉届出(想定数百社)の受付体制、テスト用ダミーデータ |
| 8 | 業務量前提 | 対象事業者数・申告件数・還付件数の想定(サイジングと画面設計の前提。石油石炭税の納税者数が参考) |

### 6.4 スケジュール上の制約

- **2027年度内**: 政省令(単価・係数・様式・期別・延納/担保)確定 → 要件凍結はここ
- **2028年度**: 徴収開始 → 政省令確定から稼働まで1年未満の可能性があるため、**6.3-6のパラメータ化戦略が事実上の必須要件**
- GX推進機構は2026年4月から排出量取引(GX-ETS)システムを先行運用 → 事業者マスタ・認証基盤の共用可否を早期に確認すべき
