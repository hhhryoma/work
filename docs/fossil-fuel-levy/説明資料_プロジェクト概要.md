# 化石燃料賦課金管理システム プロジェクト概要(参画者向け説明資料)

新規参画者が30分で「制度」「システム」「いまの状態」を把握するための資料。詳細は各設計書へ。

## 1. 化石燃料賦課金とは(3分で分かる制度)

- **何か**: 化石燃料(原油・石油製品・LNG・石炭等)の輸入事業者等に、燃料由来の**CO₂の量に応じて**課される賦課金。カーボンプライシングの一種
- **根拠法**: GX推進法(2023年5月成立・令和5年法律第32号)+2025年5月改正法(徴収実務を法定化)
- **いつから**: **2028年度**徴収開始。手続の細目を定める政省令は**2027年度内**に確定見込み
- **誰が徴収**: **GX推進機構**(経済産業大臣認可法人)。税ではないので税務署・税関ではない
- **何に使う**: GX経済移行債(20兆円規模の先行投資)の償還財源
- **いくら**: 単価は毎年度**政令**で決定。想定値は2028年度 約2,500円/t-CO₂(確定値ではない)

計算の基本式(これだけ覚える):

```
賦課金額 = 燃料数量 × CO₂排出係数 × 賦課金単価(円/t-CO₂)
```

## 2. お金と情報の流れ(全体像)

```
事業者(輸入者等)                GX推進機構(本システム)         経産省(収納側)
 │ ①届出・申告 ─────────────▶ 受付・審査・賦課金額の確定
 │                              │ ②賦課決定情報(IF-1o) ────▶ 収納受入準備
 │ ③納付(本システム外) ・・・・・・・・・・・・・・・・・・・・・・▶ 収納
 │                              ◀─ ④納付完了情報(IF-1a) ──── │
 │                              ⑤消込・延滞金確定・過納検知
 │ ⑥還付申請/更正の請求 ────▶ ⑦還付審査・減額更正
 │ ◀──── ⑧還付振込(全銀) ──── │
```

本システムは②〜⑦を担う。**納付書・督促状の発行はスコープ外**、③の収納は経産省側(この分担自体が協議事項)。

## 3. 還付の2系統(本プロジェクト最初の山場だった論点)

| | 過納還付 | 用途還付 |
|---|---|---|
| 起点 | 当初の賦課が**誤っていた**(納め過ぎ) | 賦課は正しいが、**特定用途**(輸出等の国内非使用・原料用途)に使った |
| 手続 | **更正の請求** → 機構が審査し**減額更正** → 還付 | **還付申請**(独立の申請。更正は発生しない) |
| 上乗せ | **還付加算金**(利子相当)が付く | 原則なし |
| モデル | 国税通則法23条(更正の請求) | 石油石炭税の用途別還付(国税庁D7-33/34/37等) |

※「修正申告」は増額専用であり、還付には使えない(修正申告で還付はできない)。

## 4. 主要業務マップ(詳細は業務仕様書 §1)

| 系 | 業務 | ひとこと |
|---|---|---|
| A | 事業者管理 | 届出の受付、事業者マスタ、還付先口座 |
| B | 申告 | 申告受付、輸入通関実績との突合審査、無申告管理 |
| C | 決定・更正 | 職権決定、増額/減額更正、通知書交付(多段決裁) |
| D | 収納 | 経産省連携の取込・消込、滞納・延滞金の把握。【候補】延納・担保 |
| E | 還付 | 過納還付・用途還付・支払(充当判定→加算金計算→全銀振込) |
| F | 共通 | 単価・係数マスタ(年度世代管理)、統計・報告 |

## 5. 設計上の三大制約(全員が知っておくべき)

1. **政省令待ち**: 期別・期限・単価・係数・利率・様式は2027年度内確定 → **すべてパラメータ化**し、確定後に改修なしで設定変更できる構造が必須(稼働まで1年を切る可能性)
2. **収納の分担**: 「経産省が収納し納付完了情報を連携」は前提であって合意済みではない。**納付番号の採番主体(IF-1o)が最優先協議事項**
3. **金銭直結**: 賦課・還付は処分性があり金銭に直結 → 多段決裁、監査証跡、教示文(不服申立て)、交付日管理が全機能に横串で効く

## 6. 用語集

| 用語 | 意味 |
|---|---|
| 賦課金単価 | 円/t-CO₂。毎年度政令で決定(国会議決不要。「税」でない理由のひとつ) |
| CO₂排出係数 | 燃料1単位あたりのCO₂トン数。政令別表想定(温対法係数準拠の見込み) |
| 更正 | 確定した賦課金額を機構が職権または請求に基づき訂正すること(増額/減額) |
| 更正の請求 | 事業者が「賦課金額が過大」と是正を求める手続。認められると減額更正→過納還付 |
| 還付加算金 | 過納金に付く利子相当額。減額更正確定後に機構が計算 |
| 延滞金 | 納期限超過に対するペナルティ。納付日をもって確定計算 |
| 充当 | 還付金を同一事業者の未納債権へ先に振り向けること。差額のみ振込 |
| 消込 | 納付完了情報を賦課決定(債権)と突合し納付済みにする処理 |
| 過納検知 | 納付額>債権残高となった状態の自動検出。還付業務へ自動起票 |
| 延納 | 納期限の延長(参考: 石油石炭税は担保提供とセットで最長2か月)。【候補】業務 |
| 教示文 | 処分通知に必須の「不服申立てできる旨・申立先・期間」の記載 |
| 賦課決定 | 本文書群では「賦課金額の確定(申告による確定を含む)」の意の便宜上の呼称 |
| GビズID | 法人向け共通認証(事業者ポータルのログイン方式の第一候補) |
| NACCS | 輸出入通関システム。申告数量の突合データ源の候補 |
| 全銀フォーマット | 銀行振込データの標準形式。還付支払で使用 |

## 7. FAQ(参画者からよく出る質問)

**Q. なぜ税務署ではなくGX推進機構が徴収するのか?**
A. 化石燃料賦課金は法律上「税」ではないため。単価を政令で機動的に決められる設計。ただし徴収手続(延滞金・滞納処分等)は税に準じて法定されている。

**Q. 納付書を発行しないのに、どうやって事業者は納付するのか?**
A. 収納は経産省側の仕組みで行う前提(本システム対象外)。ただし収納側が入金を紐づけるには機構からの賦課決定情報(納付番号)連携が必要 — これがIF-1o論点。

**Q. 石油石炭税と二重取りでは?**
A. 別制度として併存する。既存の石油石炭税(+温対税)に上乗せの形。用途還付など二重負担の調整は双方の制度にあり、還付窓口も別(税=税務署、賦課金=機構)。

**Q. 数字が決まっていないのにどう設計するのか?**
A. 期別・単価・係数・利率は全部パラメータ(マスタ)に外出しし、画面・計算ロジックは値に依存しない構造にする。モックの数値はすべて仮置き。

**Q. 排出量取引(GX-ETS)との関係は?**
A. 同じGX推進法・同じ機構の制度だが本システムのスコープ外。ただし事業者マスタ・認証基盤の共用可否は早期確認事項。
