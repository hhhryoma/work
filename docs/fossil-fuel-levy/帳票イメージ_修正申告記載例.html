還付が出た申告を修正する場合の記載例

石油石炭税納税申告書(法第15条用)で、期限内申告で還付を受けた月について、後から引取り数量の計上漏れが見つかり修正申告する場面です。還付が減り、その差額を納付します。

税関が公表している様式と「書き方」をもとに再現したイメージで、公式の記載例ではありません。事業者名・所在地・輸入申告番号・統計細分・控除額はすべて架空です。税率は2026年11月に確認した租税特別措置法の特例税率で計算しています。実際の提出には税関の最新様式を使い、記載方法は所轄の税関に確認してください。

  • 税額様式に印字済みの文字
  • 2,800申告者が記入する内容
  • 不要欄の抹消(斜線)
  • 修正不要文字の抹消(二重線)
  • ※税関が記入する欄(網掛けは本ページでの目印)

記載ポイント

番号は紙面の赤い番号に対応します。根拠は税関の「石油石炭税納税申告書(法第15条用)の書き方」と国税通則法19条です。

  1. 標題は当初申告と同じ年月修正する対象の月(引き取った年月)を書きます。日付欄は修正申告書を提出する日です。
  2. 「修正申告書」だけを残す括弧内の「期限後申告書」と「還付請求申告書」を二重線で消します。
  3. 数量と税額は修正後の全体を書く増えた分だけではなく、計上漏れを含めた月全体の数量・税額を書きます。付表も修正後の内容で作り直します。
  4. ②は当初申告で受けた控除額修正申告書では新たな控除は受けられません。この例では、期限内申告で受けた控除額をそのまま書いています(下の注を参照)。
  5. ③は修正後の還付額②−①を計算し直します。①が増えたので、還付は3,294,000円から1,893,034円に減ります。④は該当がないので斜線です。
  6. ⑤は修正前の還付額に「−」を付ける直前の申告書の「還付を受ける金額」を、マイナスの印を付けて書きます。直前が納付だった場合は「納付すべき税額」をそのまま書きます。
  7. ⑥が今回納付する額④−③−⑤ = 0 − 1,893,034 −(−3,294,000)= 1,400,966円。100円未満を切り捨てて1,400,900円です。修正申告書を提出する日までに納付します。
  8. Ⓛに理由を書き、Ⓚは書かない修正申告をすることになった理由と事情を書きます。還付口座(Ⓚ)は期限内申告で還付を受けるときだけの欄なので斜線です。

注(②の書き方): 「書き方」は、修正申告書では控除・還付を受けられないとしています。一方で、⑥の算式(④−③−⑤)には③が入っており、修正申告書に還付額が残る場合を前提にしていると読めます。そこでこの例は「期限内申告で受けた控除額は②に残し、新たな控除は足さない」という解釈で書いています。この解釈は税関に確認したものではありません。

検算

納付額を「納付は正、還付は負」の符号つきで見ると、修正後から修正前を引くだけで⑥になります。

項目式金額
修正前の納付額当初の③に「−」−3,294,000 円
修正後の納付額④ − ③ = 0 − 1,893,034−1,893,034 円
差額(−1,893,034)−(−3,294,000)+1,400,966 円
⑥ 差引納付すべき税額(100円未満切り捨て)1,400,900 円

差額は、計上漏れだった原油の税額(500.345 kL × 2,800円 = 1,400,966円)と一致します。このほかに過少申告加算税と延滞税がかかりますが、申告書には書きません。
